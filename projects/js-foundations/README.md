# Personal Dashboard (`js-foundations`)

The hands-on project for **Part 10 (JavaScript Foundations)** and **Part 20 (TypeScript
Foundations)**. You build a small interactive personal dashboard from scratch in plain JavaScript,
learning the language as you go, then upgrade the whole thing to TypeScript.

## Run it

```bash
# From the repo root, once:
pnpm install

# Start the dev server (live-reloads as you edit):
pnpm js
```

Vite will print a local URL (e.g. http://localhost:5173). Open it in your browser. Edit
`src/main.js` and the page updates instantly.

## What you'll build into it

- A time-aware greeting and a live clock
- A to-do list with add / complete / delete
- A quick-notes box that persists with `localStorage`
- Small widgets that pull data from a public API

Each feature maps to specific lessons in Parts 10–20.
